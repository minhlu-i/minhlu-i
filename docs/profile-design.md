# Profile design

The profile uses a dark violet/cyan workbench theme: a neofetch-style terminal card (light and dark variants), a featured project card, and readable Markdown. English copy keeps the profile accessible to an international audience.

## Content sources

- The previous profile establishes backend development, TypeScript, NestJS, PostgreSQL, Python, Docker, architecture/gamification interests, and social links.
- The public [workstation README](https://github.com/minhlu-i/workstation#readme), checked on 2026-10-01, establishes the featured project's platforms, implemented domains, CLI tools, backups, verification, and planned workspace organization. AI workflow copy refers to documented Codex and Claude Code tooling; it does not claim authorship of those products.
- No private projects, invented metrics, employers, or unverified achievements are included.

The copy and SVG artwork are original; reference assets were not copied.

## Neofetch card

`assets/neofetch-dark.svg` and `assets/neofetch-light.svg` are generated by `scripts/today.py` from `scripts/config.py`; do not edit them by hand. The workflow `.github/workflows/build.yml` re-renders them daily at 00:00 (UTC+7), on changes to `scripts/`, and on manual dispatch, using the `ACCESS_TOKEN` repository secret. GitHub stats (repos, stars, commits, followers, lines added/removed) come from the GraphQL API; per-repository line counts are cached in `cache/`. The layout follows [Andrew6rant's profile README](https://github.com/Andrew6rant/Andrew6rant); the script and art are written for this repository. `assets/profile-hero.svg` is kept but no longer referenced.

## Maintenance

Edit `README.md` for content, `scripts/config.py` for the neofetch card, and `assets/workstation-card.svg` for artwork. All images are static SVGs without scripts, external fonts, or embedded HTML. Main headings, project descriptions, and links remain text. Technology badges use Shields.io.

Update implementation status when the project's public README changes. Keep planned work identified as planned. Check the profile on GitHub after publishing; local SVG inspection does not verify GitHub's final image proxy or Markdown layout.
