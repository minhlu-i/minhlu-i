# Profile design

The profile uses a dark violet/cyan workbench theme: a custom hero, a featured project card, and readable Markdown. English copy keeps the profile accessible to an international audience.

## Content sources

- The previous profile establishes backend development, TypeScript, NestJS, PostgreSQL, Python, Docker, architecture/gamification interests, and social links.
- The public [workstation README](https://github.com/minhlu-i/workstation#readme), checked on 2026-10-01, establishes the featured project's platforms, implemented domains, CLI tools, backups, verification, and planned workspace organization. AI workflow copy refers to documented Codex and Claude Code tooling; it does not claim authorship of those products.
- No private projects, invented metrics, employers, or unverified achievements are included.

The copy and SVG artwork are original; reference assets were not copied.

## Maintenance

Edit `README.md` for content and `assets/profile-hero.svg` / `assets/workstation-card.svg` for artwork. Both images are static SVGs without scripts, external fonts, or embedded HTML. Main headings, project descriptions, and links remain text. Technology badges use Shields.io.

Update implementation status when the project's public README changes. Keep planned work identified as planned. Check the profile on GitHub after publishing; local SVG inspection does not verify GitHub's final image proxy or Markdown layout.
